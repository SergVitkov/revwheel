# RevWheel

A social club for car people. The feed works like Instagram and Threads, but the only things you can publish are a modification, a repair, or a guide — each one attached to a car. Car cards carry the spec sheet, the build, and the service log. The map shows approximate meetups for people who opted in.

```bash
npm install
npm run dev
```

Open the feed, the car card, a guide, and the map. Photos are real cars and workshop shots.
